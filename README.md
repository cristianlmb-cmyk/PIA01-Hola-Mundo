
# PIA01 - Hola Mundo

Este repositorio lo he creado para la primera tarea del módulo de Programación en Inteligencia Artificial.

El objetivo es aprender a utilizar GitHub para guardar y compartir proyectos, además de crear un primer programa sencillo en Python.

## Contenido del repositorio

- **README.md:** archivo con la descripción de la actividad.
- **hola_mundo.py:** programa que muestra el mensaje "Hola Mundo" por pantalla.
